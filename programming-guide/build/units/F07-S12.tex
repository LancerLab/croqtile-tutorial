\subsection*{Early return from \texttt{parallel}}

Use \texttt{yield} to return early from a \texttt{parallel} block. It generates a \texttt{return;} instruction that ends device execution for the current instance.

\begin{lstlisting}[language=croqtile,caption={Early return from parallel}]
parallel p by BLK_CNT: block {
  parallel q by THR_CNT : thread {
    if (cond) yield;
    ...
  }
}
\end{lstlisting}

\begin{pitfall}[Common pitfall]
The \texttt{yield} keyword currently will \textbf{not} do any compile-time nor runtime checks. Be careful about synchronization safety.

\end{pitfall}

Check an early exit against the remaining synchronization in the region. An instance that leaves before triggering an event can strand its consumer; an instance that skips a required collective operation can strand its peers. A tail guard is easiest to reason about when all instances responsible for the same tile make the same decision.
