\subsection*{Easy to Use}

You work on tensors and tiles, not raw buffers and pointers. DMA transfers, memory allocation, and synchronization that take dozens of lines of hand-written target code reduce to a single \texttt{dma.\allowbreak{}copy .\allowbreak{}.\allowbreak{}.\allowbreak{} =\textgreater{} .\allowbreak{}.\allowbreak{}.\allowbreak{}} statement. Every construct lowers to the same code you would write by hand: zero-cost abstraction, no runtime overhead, no hidden allocations.
