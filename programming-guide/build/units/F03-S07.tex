\subsection*{What You Have So Far}

The constructs introduced so far assemble into one skeleton: a \texttt{\_\_co\_\_} function with typed, shaped parameters and a return value; \texttt{parallel} and \texttt{.at()} for element-wise computation; \texttt{lhs.span} for deriving output shapes from inputs; and the host-side \texttt{make\_spandata} / \texttt{.view()} API for creating and passing tensors.

Section~\ref{sec:2-9} introduces \texttt{dma.copy} and \texttt{chunkat} to express block-level data movement.
