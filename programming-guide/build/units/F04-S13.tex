\subsection*{\texttt{\#}: Compose and Extent}

The unary form \co@#p@ retrieves an index's upper bound. The binary form \co@p # i@ combines an outer index with an inner one: its value is \co@p * #i + i@, and its bound is \co@#p * #i@. For eight tiles containing 16 elements each, tile 2 and inner element 5 identify element 37 in a range of 128 elements.
