\subsection*{Inter-region signaling with events}

When \texttt{inthreads.\allowbreak{}async} creates concurrent regions, those regions need a way to communicate. Croqtile provides \textbf{events}.

\begin{lstlisting}[language=croqtile,caption={Inter-region signaling with events}]
shared event full;
shared event empty;
\end{lstlisting}

Events have two operations:

\begin{itemize}[leftmargin=1.6em]
\item \textbf{\texttt{trigger name}} --- record that a condition is met (e.g., "data is ready")
\item \textbf{\texttt{wait name}} --- block until the corresponding \texttt{trigger} fires
\end{itemize}

The producer calls \texttt{trigger full} after writing a tile to record "data ready." The consumer calls \texttt{wait full} before reading, blocking until that trigger arrives. Symmetrically, the consumer triggers \texttt{empty} after finishing its read (the buffer can be reused), and the producer waits on \texttt{empty} before writing the next tile.

This is a \textbf{bounded buffer} built from two events --- \texttt{full} records that a slot holds data; \texttt{empty} records that it is free to fill.
