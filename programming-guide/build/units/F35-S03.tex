\subsection*{Event Instances}

In Croqtile, events are associated with the storage specifier, either \texttt{global}, \texttt{shared}, and \texttt{local}. Such storage specifier specifies the event instances.

\begin{lstlisting}[language=croqtile,caption={Event Instances}]
__co__ void foo() {
  global event ge;     // single instance in the tileflow program
  parallel p by 2 {    // shared level
    shared event se;   // two instances, 1 for each shared instance
    parallel q by 6 {  // local level
      local event le;  // 12 instances in total, 6 for each shared instance
    }
  }
}
\end{lstlisting}

The comments identify the event instances. As with spanned-data declarations, the storage specifier determines the level at which an event is stored and shared. An implementation may represent events with Boolean state at that storage level; the number of instances follows the corresponding parallel scope.
