Clone the repository and run the automated setup:

\begin{lstlisting}[language={},caption={Clone and prepare}]
git clone https://github.com/LancerLab/croqtile.git
cd croqtile
make setup-core
\end{lstlisting}

\texttt{make setup-\allowbreak{}core} pulls git submodules and downloads the required versions of Flex, Bison, FileCheck, and GoogleTest if they are not already present. Once setup finishes, build the compiler:

\begin{lstlisting}[language={},caption={Build the compiler}]
make
\end{lstlisting}

Then run the test suite; it is the check that the freshly built compiler is sound:

\begin{lstlisting}[language={},caption={Run the test suite}]
make test
\end{lstlisting}

If all tests pass, the \texttt{croq} binary is ready in your build directory. Add it to your \texttt{PATH} or invoke it by its full path. The next step compiles a minimal program to confirm the installation end to end.
