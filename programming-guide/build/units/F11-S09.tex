\subsection*{Putting it together}

Choose the first check from the symptom. If a tile has the wrong dimensions, inspect its shape with \co@println!@ before running the program. If the shape is right but the values are wrong, print one tile or add an assertion near the suspect operation. A stalled pipeline calls for event and iteration counts; a regular pattern of incorrect matrix elements calls for a layout check. Use a debugger when these checks point to an address or lifetime problem. Keep temporary output behind a preprocessor guard so it can be removed from a normal build:

\begin{lstlisting}[language=croqtile,caption={Guarding debug prints}]
#ifdef DEBUG_PRINT
  println("tile_k=", iv_k, " accum=", mc);
#endif
\end{lstlisting}

\begin{lstlisting}[language={},caption={Debug and production builds}]
croq kernel.co -DDEBUG_PRINT -o kernel    # debug build
croq kernel.co -o kernel                   # production build
\end{lstlisting}
