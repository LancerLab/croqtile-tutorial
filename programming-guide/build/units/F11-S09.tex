\subsection*{Putting it together}

Work from cheap to expensive: \texttt{println!} (compile-time shapes) \(\rightarrow\) guarded \texttt{println} on one tile (runtime values) \(\rightarrow\) event/stage prints (synchronization) \(\rightarrow\) pattern analysis (layout) \(\rightarrow\) an interactive debugger (pointer bugs). Guard runtime prints behind \texttt{\#ifdef} so they vanish in production:

\begin{lstlisting}[language=croqtile,caption={Guarding debug prints}]
#ifdef DEBUG_PRINT
  println("tile_k=", iv_k, " accum=", mc);
#endif
\end{lstlisting}

\begin{lstlisting}[language={},caption={Debug and production builds}]
croq kernel.co -DDEBUG_PRINT -o kernel    # debug build
croq kernel.co -o kernel                   # production build
\end{lstlisting}
