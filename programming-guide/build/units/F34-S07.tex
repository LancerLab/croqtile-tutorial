\subsection*{Make it Asynchronous}

Like \texttt{parallel-by}, \texttt{inthreads} can execute asynchronously. This lets instances running a divergent region proceed independently of those outside it, expressing MPMD behavior within an SPMD program:

\begin{lstlisting}[language=croqtile,caption={Make it Asynchronous}]
__co__  void foo() {
  parallel p by 6 {
    inthreads.async (p <= 2) {
      // divergent code for thread 0, 1, 2 (thread-mask: 000111)
    }
    inthreads.async (p > 2) {
      // divergent code for thread 3, 4, 5 (thread-mask: 111000)
    }
    sync.shared; // sync point
                 // all 'inthreads' paths must get executed
  }
}
\end{lstlisting}

The example divides the parallel instances into two groups without synchronizing after each \texttt{inthreads} block, allowing the groups to execute concurrently. The subsequent \texttt{sync.shared} establishes a synchronization point that both paths must reach before execution continues.

Only the outer \texttt{inthreads} can be declared as asynchronous. Programmers will get a compile-time error when using \texttt{inthreads.\allowbreak{}async} for any inner \texttt{inthreads} block.
