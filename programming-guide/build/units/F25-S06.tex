\subsection*{Return Type and Type Deduction}

Similar to the input, \emph{spanned data} and \emph{integer} are valid output types. The \emph{void} type is also allowed if nothing is returned.

In addition to the explicit return type annotation, Croqtile supports type inference on returns. For example:

\begin{lstlisting}[language=croqtile,caption={Return Type and Type Deduction}]
__co__ auto foo() {
  f32 [7, 16] result;
  // ...
  return result;
}
\end{lstlisting}

Here, \co@auto@ is inferred as \co@f32 [7, 16]@ from \co@result@. This is useful when the output shape is derived inside the function: changing that derivation does not require a matching edit to the return annotation. Use an explicit type when a fixed return shape is part of the interface you want to enforce.
