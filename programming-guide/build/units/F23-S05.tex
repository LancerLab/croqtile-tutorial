\subsection*{Difference with C++ pre-processing}

Croqtile preprocessing runs much earlier than c++ preprocessing. The workflow of croqtile compilation is as shown below:

\begin{lstlisting}[language=croqtile,caption={Differences from C++ Preprocessing}]
chore-preprocessing -> croqtile compilation -> c/c++ preprocessing -> c/c++ compilation
\end{lstlisting}

Croqtile preprocessing coordinates macros across the host and device portions of a program. Its implementation substitutes macros and handles conditional compilation within Tileflow functions, while leaving other preprocessing to the C++ preprocessor. This division can produce differences from ordinary C++ preprocessing.
