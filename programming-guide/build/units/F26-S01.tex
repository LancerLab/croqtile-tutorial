\subsection*{\emph{Factor} Target Specific Details}

Targets such as \emph{factor} require C linkage for device functions, expressed with \texttt{extern "C"}. Function templates cannot have C linkage, so Croqtile provides wrappers to support them:

\begin{lstlisting}[language=croqtile,caption={A cok block around device code}]
__cok__ {
extern "C" void bar(int v) {};  // v is a compile-time constant
}
__co__ void foo() {
  parallel p by 1 { call bar(3); }
}
\end{lstlisting}

Programmers can turn \texttt{bar} into a function template, like following:

\begin{lstlisting}[language=croqtile,caption={The block after factoring target-specific details}]
__cok__ {
template <int v> void bar() {};
// compiler generate a explicit function template specialization:
// template<> void bar<3>() {};
}
__co__ void foo() {
  parallel p by 1 { call bar<3>(); }
}
\end{lstlisting}

Croqtile can generate a wrapper for the \co@bar<3>@ specialization. The function template itself has C++ linkage; the wrapper provides the target-facing entry point.

As the implementation differs from other targets, you may utilize \texttt{-kt} to enable such functionality for \emph{croqtile-factor} compilation.
