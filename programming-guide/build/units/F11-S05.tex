\subsection*{Verbose mode: \texttt{-v}}

Pass \texttt{-v} (or \texttt{--verbose}) to the compiler to see the external commands it invokes --- which preprocessor, which code generator, which \texttt{c++} invocation:

\begin{lstlisting}[language={},caption={Verbose mode: -v}]
croq kernel.co -v -o kernel
\end{lstlisting}

This is useful when you suspect the compiler is passing wrong flags to \texttt{c++} or when you need to see the exact generated file paths for manual inspection.
