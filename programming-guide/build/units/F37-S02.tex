\subsection*{Spanned Types in Croqtile}

A spanned type combines an element type, such as \co@f32@, with a shape. The same shape can be reused with another element type, and a derived shape can describe a tile without changing what each element stores.

The spanned type by itself does not allocate storage for the data. Instead, it serves as a blueprint for defining how the data will be organized in memory, allowing for runtime flexibility and optimizations.
