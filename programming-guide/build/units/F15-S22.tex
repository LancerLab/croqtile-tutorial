\paragraph*{In short}

Croqtile expresses SPMD programs in a C++-style DSL embedded in C++. It reduces the low-level work of moving data between storage levels, particularly through DMA, and is therefore also described as a dataflow DSL. Its purpose is to support everyday kernel development by letting programmers focus on the organization of computation rather than repetitive implementation details.

Feedback from using these constructs helps guide further improvements to the language.
