\paragraph*{In short}

Events order asynchronous \texttt{inthreads} regions. A \texttt{trigger} sets an event or event array to \textbf{SET}. A \texttt{wait} blocks until the event is triggered, then resets it to \textbf{UNSET}.

Pair event triggers and waits carefully. Incorrect ordering can cause deadlocks that are difficult to diagnose.
