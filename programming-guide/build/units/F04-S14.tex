\subsection*{Compose: \texttt{outer \# inner}}

\begin{lstlisting}[language=croqtile,caption={Compose: outer inner}]
output.at(tr # i, tc # j)
\end{lstlisting}

This combines a tile coordinate with an in-tile coordinate to produce a coordinate in the full tensor.

For an outer tile index \co@tr@ and an inner index \co@i@, \co@tr # i@ has value \co@tr * #i + i@. If a tile has 16 rows, tile 2 and inner row 5 identify global row 37. Its bound is the product of the two bounds. Operand order matters because the inner bound supplies the stride.
