\subsection*{\texttt{chunkat(...)}: equal partitioning}

\begin{lstlisting}[language=croqtile,caption={chunkat(...): equal partitioning}]
lhs.chunkat(tr, tc)
\end{lstlisting}

The \co@chunkat@ expression divides each dimension according to the corresponding index bound. With input shape \co@[64, 128]@ and \co@parallel {tr, tc} by [4, 8]@, it selects a \co@[16, 16]@ tile. The current values of \co@tr@ and \co@tc@ select which tile, while their bounds determine its size.

That makes \texttt{chunkat} the natural tool when your tiling follows the parallel decomposition directly.
