\subsection*{Explicit Masking/Condition}

A thread mask describes which SPMD instances execute a region. Within the code for a single instance, it appears as a Boolean condition, usually a comparison involving a thread identifier.

In the examples that follow, Croqtile experimentally supports explicit masking of the \texttt{foreach} block, which masks off loop code as a whole. For example:

\begin{lstlisting}[language=croqtile,caption={Explicit Masking/Condition}]
__co__  void foo() {
  parallel p by 6 {
    with q in [2] {
      foreach q if (p == 0) {
        // this iteration only work for parallel thread 0
      }
    }
  }
}
\end{lstlisting}
