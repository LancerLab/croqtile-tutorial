\subsection*{Embedding Croqtile within C++}

Croqtile is a DSL embedded in C++. Its compiler translates Croqtile functions into C++ and implicitly includes \texttt{croqtile.h} so the generated code can interoperate with ordinary C++. For example:

\begin{lstlisting}[language=croqtile,caption={Embedding Croqtile within C++}]
// some C++ code
__co__ void croqtile_function() {
  // croqtile code
}
// another C++ code
void foo() {
  croqtile_function();
}
\end{lstlisting}

The \co@__co__@ prefix identifies the function body Croqtile translates. Ordinary C++ calls that function by its declared name. The host-facing interface uses shaped buffer wrappers so the call carries dimensions as well as an address.

In addition, certain Croqtile-specific types are introduced to ensure consistency between Croqtile function arguments and their respective callers. Considering that there are some important programming elements missing, you will defer the introduction of such details until the data types are explained.
