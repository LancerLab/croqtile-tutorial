\subsection*{Bounded Types}

Bounded types consist of \textbf{Bounded Scalar} and \textbf{Bounded ITuple}. Bounded Scalar takes a range of [0, ub), where 'ub' represents its upper bound. Therefore, if an integer 'p' is set as bounded, it should also be associated with a specific upper bound. To establish such associations, programmers must code explicitly inside the \emph{Control Structures} of 'parallel-by' and 'with-in', which will be introduced later.

A bounded tuple extends the same idea to several dimensions. Each component has its own bound, and an \co@mdspan@ describes the combined range. For example, a tuple bounded by \co@[4, 8]@ can identify one of 32 positions. Section 2.7 shows how to declare and iterate over these indices.
