\subsection*{Bounded Types}

A bounded integer carries a value and an exclusive upper bound. In \co@parallel p by 6@, its possible values are 0 through 5 and its upper bound is 6. A tile selection can therefore determine both which piece \co@p@ identifies and how many pieces exist. The \co@parallel-by@ and \co@with-in@ constructs establish this association.

A bounded tuple extends the same idea to several dimensions. Each component has its own bound, and an \co@mdspan@ describes the combined range. For example, a tuple bounded by \co@[4, 8]@ can identify one of 32 positions. Section 2.7 shows how to declare and iterate over these indices.
