\subsection*{Conditional Compilation}

Croqtile supports conditional compilation with directives including \texttt{\#if}, \texttt{\#ifdef}, \texttt{\#ifndef}, \texttt{\#else}, and \texttt{\#endif}:

\begin{lstlisting}[language=croqtile,caption={Conditional Compilation}]
#define PATH0
// some host code
__co__ foo() {
#ifdef PATH0
// some code related to PATH0
#else
// other code
#endif
}
// host control
#ifdef PATH0
// ...
#else
// ...
#endif
\end{lstlisting}

The same preprocessing conditions can control both host C++ and Croqtile code.

The preprocessor is still being extended, and full C preprocessing support is not planned: a C feature is picked up only when a program actually needs it.
