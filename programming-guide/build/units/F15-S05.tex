\subsection*{Scalar Types}

Croqtile provides \textbf{integer} and \textbf{Boolean} scalar types. Its integer type is a signed 32-bit value, like C++ \texttt{int} or \texttt{int32\_t}, with range $-2^{31}$ to $2^{31}-1$. The following example uses it in a variable declaration and a function definition.

\begin{lstlisting}[language=croqtile,caption={Scalar Types (fragment)}]
int a;
__co__ int foo(int b) { return b; }
\end{lstlisting}

Integers support arithmetic, shifts, and logical operations with C++ syntax. The plain \texttt{int} is a signed 32-bit value; when a control value needs a different range or signedness, \texttt{s8}, \texttt{s16}, \texttt{s64} and \texttt{u8}, \texttt{u16}, \texttt{u32}, \texttt{u64} are available.

The Boolean type corresponds to C++ \texttt{bool}. Boolean operations and conversions between Boolean and integer values follow C++ rules.
