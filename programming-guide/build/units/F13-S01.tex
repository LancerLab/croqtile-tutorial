From here the path is step by step. The chapters that follow start with the smallest kernel that compiles and evolve a single running example through progressively richer matmul variants, so each new idea appears in a concrete, working program and every major construct is met before the end. The next step is a practical one: build the compiler so that each of those programs can be run rather than only read. Section~\ref{sec:1-2} lists what you need, and Section~\ref{sec:1-3} walks through the build.
