\subsection*{Cost and Limitations}

Dynamic dimensions leave less information available during compilation. Some constraints must therefore be checked at runtime. Croqtile places shape checks in generated host code where possible; application-specific requirements may still need assertions.

Anonymous and symbolic dimension syntax is restricted to spanned-data parameters. An internal buffer can derive its shape from an input, but it cannot introduce a new unspecified dimension with \co@?@ or a new symbolic name. The following declaration is rejected:

\begin{lstlisting}[language=croqtile,caption={Cost and Limitations}]
__co__ void foo() { f32 [M] d;} // compile-time error: can not applied to the spanned buffer
\end{lstlisting}
