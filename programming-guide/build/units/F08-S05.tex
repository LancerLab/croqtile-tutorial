\subsection*{\texttt{with tile\_\allowbreak{}k in 16}}

The statement \co@with tile_k in 16@ gives \co@tile_k@ the range from 0 through 15, with upper bound \co@#tile_k = 16@. It does not run the body 16 times. A later \co@foreach tile_k@ performs that iteration. Separating the binding from the loop lets a pipeline select tile 0 before the loop and then iterate over the remaining tiles.
