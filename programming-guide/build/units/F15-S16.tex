\subsection*{The 'foreach' Block}

Once the \emph{bounded-ituple} is defined by the 'with-in' clause, programmers can loop over the bounded-ituples/bounded-integers. In Croqtile, this is simple.

\begin{lstlisting}[language=croqtile,caption={The foreach Block}]
with x in [10] {
  foreach x {
    // do something with each x
  }
}
\end{lstlisting}

Each iteration gives the bounded variable a current value for the duration of the loop body. The bound stays fixed. Use that current value to select data, and use the bound when deriving how many pieces the data is divided into. Declaring a parallel index instead would assign one value to each independent instance rather than visit the values in order.
