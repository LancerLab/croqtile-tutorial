\subsection*{Prerequisites}

\begin{itemize}[leftmargin=1.6em]
\item Basic C++ (functions, pointers and arrays) and the idea of a shaped tensor
\item Some familiarity with parallel programs: independent work items, tiles, and coordination between concurrent regions
\item A machine on which you can build the compiler (see Section~\ref{sec:1-3})
\end{itemize}
