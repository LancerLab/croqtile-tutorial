\subsection*{\texttt{\_\allowbreak{}\_\allowbreak{}co\_\allowbreak{}\_\allowbreak{} auto} return type}

\texttt{\_\allowbreak{}\_\allowbreak{}co\_\allowbreak{}\_\allowbreak{} auto matmul(.\allowbreak{}.\allowbreak{}.\allowbreak{})} lets the compiler infer the return type from \texttt{return output}.

\begin{center}\small\emph{This example uses \texttt{s32} with scalar accumulation --- a simplified style to isolate the \texttt{swap} mechanism. The same pattern applies to FP16/MMA kernels from Section~\ref{sec:3-7}.}\end{center}
