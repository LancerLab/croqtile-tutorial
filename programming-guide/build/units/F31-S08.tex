\subsection*{Heterogeneity: Transpiling to program launch}

For targets that separate host and device execution, \texttt{parallel-by} specifies both the parallel instance count and the boundary between host and device code:

\begin{itemize}[leftmargin=1.6em]
\item Code \textbf{outside} the \texttt{parallel-by} block is transpiled into \textbf{host code}.
\item Code \textbf{inside} the block is transpiled into \textbf{device code}, as illustrated below:
\end{itemize}

\begin{lstlisting}[language=croqtile,caption={Heterogeneity: Transpiling to program launch}]
__co__ void foo(...) {
  // Generate host code
  // ...
  parallel p by 6 {
    // Generate device code
    // ...
  }
  // Generate host code
  // ...
}
\end{lstlisting}

The \texttt{parallel-by} statement therefore also marks a device-program launch. Croqtile represents this boundary through the same SPMD parallelism model used to describe the work.
