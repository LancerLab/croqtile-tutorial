\subsection*{Matrix Multiply: Putting It Together}

With \texttt{parallel}, \texttt{foreach}, \texttt{dma.copy}, \texttt{chunkat}, \texttt{\#}, and space specifiers, a tiled matrix multiply is within reach.

The plan: multiply a \texttt{[128, 256]} matrix by a \texttt{[256, 256]} matrix to get a \texttt{[128, 256]} result.
