\subsection*{1. \texttt{global}}

\begin{itemize}[leftmargin=1.6em]
\item The default memory space for data in Croqtile, if no storage qualifier is specified.
\item Data defined in the global storage space is typically the most abundant and has the largest capacity. However, accessing it can be slower than accessing more localized storage.
\item Global storage suits large datasets that need to be shared across multiple processing units, such as matrices in deep learning applications or large scientific datasets.
\end{itemize}

\begin{lstlisting}[language=croqtile,caption={1. global}]
global f32 [100, 200] matrix;
\end{lstlisting}
