\subsection*{Uniform and Divergence}

Masking is an implementation-level concept. From the perspective of the SPMD programming, you typically claim the code that processes data chunks \textbf{diverges} because not all the thread instances execute the same code due to masking. And programmers should be aware of that their SPMD code is a combination of:

\begin{itemize}[leftmargin=1.6em]
\item \textbf{Uniform Code}: \emph{All threads} execute the same code path.
\item \textbf{Divergent Code}: Only the \emph{masked threads} execute the \emph{divergent} code path.
\end{itemize}

It is necessary to have the \emph{divergent} code in SPMD code to handle different real-world requirements. And from a perspective of different programming paradigm, applying \emph{divergent} code in SPMD programs can even mimic MPMD (Multiple Program Multiple Data) behavior. In MPMD, different threads execute different code. Therefore, \emph{divergence} can extend SPMD to MPMD scope conceptually.
