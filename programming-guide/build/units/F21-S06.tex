\subsection*{From Value Numbers to Expression}

After value numbering and simplification, each expression refers to its simplified value number. Croqtile uses these results to infer \texttt{mdspan} shapes.

An \texttt{mdspan} describes the number of elements in each dimension. Together with a fundamental element type, it determines the storage size of a spanned object.

Some dimensions are determined at runtime; others can be fully evaluated at compile time. Known dimensions allow storage requirements to be determined in advance. Otherwise, the compiler generates code to calculate the shape at runtime.

For nonconstant values, the compiler must reconstruct expressions from the value numbers.
