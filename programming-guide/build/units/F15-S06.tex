\subsection*{Spanned Types}

A spanned type combines a \textbf{fundamental element type} with a \textbf{multidimensional span (\texttt{mdspan})}. Neither component alone is a complete type for data with storage; Croqtile calls them \textbf{partial types}.

Separating these components lets a program manipulate shapes independently of element types. This is useful for multidimensional machine learning data: tiling divides it into smaller blocks, and data movement transfers those blocks between storage levels. Shape calculations describe these operations.
