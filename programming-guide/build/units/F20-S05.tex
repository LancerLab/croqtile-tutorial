\subsection*{\textbf{d. Compile-Time Optimization}}

One of the significant benefits of symbolic dimensions is that they can help with \textbf{compile-time optimizations}. Since Croqtile allows symbolic dimensions to be evaluated at compile time, it can potentially optimize memory layouts and kernel execution plans based on these dimensions. This can result in more efficient code generation and better performance compared to using \texttt{?} or \texttt{-1}, which may require runtime evaluation and dynamic memory allocation, hindering optimization opportunities.
