\paragraph*{In short}

The \texttt{chunkat} expression divides a buffer into smaller chunks for a DMA statement, and the shape of each chunk follows from the bound used to select it. You explored how \texttt{chunkat} can be applied to either the source or destination of a DMA statement to manage data movement between memory and processors.

Now, you may try to write a full tileflow program. Section~\ref{sec:3-6-1} puts the pieces together into a complete tileflow program.
