\subsection*{Evaluation of \emph{mdspan}}

So far, you have seen mdspan with constant values, which is sufficient for many scenarios, as high-performance device kernels often require fine-tuning based on fixed input data shapes. In these cases, the \texttt{mdspan}s are evaluated at compile-time, meaning their values do not incur extra execution time or storage overhead.

However, in some scenarios, a runtime shape (where some dimensions are determined at execution) is required for building the kernel. Croqtile supports this with \textbf{Symbolic Dimensions} for \texttt{mdspan}, which will be introduced later. In such scenarios, runtime evaluation of dimension values may be necessary. Fortunately, Croqtile manages this evaluation immediately after entering a croqtile function in the Croqtile-generated host code, resulting in negligible startup cost. \textbf{Therefore, programmers can ignore overheads related to \_mdspan\_ normally}.
