This reference covers every aspect of programming with Croqtile:

\begin{enumerate}[leftmargin=1.6em]
\item \textbf{Program structure}: How Croqtile programs are organized --- the \texttt{\_\_co\_\_} function, host-side APIs, and C++ interoperability.

\item \textbf{Shaped data}: Croqtile's type system for multi-dimensional tensors --- shapes, MDSpan, spanned data, symbolic dimensions, and dynamic shapes.

\item \textbf{Loop and parallelism}: SPMD parallelism, loop control, tiling, and iteration constructs.

\item \textbf{Data movement}: DMA statements, tiling with \texttt{chunkat}, TMA, swizzle, and advanced data movement patterns.

\item \textbf{C++ embeddings}: Input/output conventions, \texttt{\_\_cpp\_\_} inline blocks, macros, and preprocessor integration.

\item \textbf{Optimization patterns}: Tileflow optimizations, async DMA patterns, multi-buffering, and performance tuning techniques.
\end{enumerate}
