\subsection*{\emph{mdspan} with \textbf{Anonymous Dimension}}

Croqtile supports shape dimensions with unknown values, similar to many high-level machine learning languages. The simplest method is to use \textbf{Anonymous Dimension} in \texttt{mdspan}:

\begin{lstlisting}[language=croqtile,caption={A kernel with an unknown dimension}]
__co__ auto foo(s32 [?, 1, 2] input) { ... }
\end{lstlisting}

Here, the question mark \texttt{?} represents a compile-time unknown value. Any positive integer could be assumed here. However, the value must be provided at runtime, as the following example shows:

\begin{lstlisting}[language={},caption={The caller supplying that dimension}]
void bar(int * data, int dim0) {
  foo(croq::make_spanview<3>(data, {dim0, 1, 2}));
}
\end{lstlisting}

The first dimension of \texttt{input} comes from the spanned input passed to \texttt{foo}; \texttt{bar} obtains the value from its caller at runtime. For example, it may come from a configuration file or a shape calculation in a machine learning framework.

An anonymous dimension is sufficient when only its size matters within one input. It does not give two inputs a shared name for a dimension that must agree. Matrix multiplication needs precisely that relationship: the left operand's column count must equal the right operand's row count.
