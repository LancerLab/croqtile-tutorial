In Croqtile, you can bind a \texttt{parallel-by} block to a specific stream using angle-bracket syntax:

\begin{lstlisting}[language=croqtile,caption={Stream Binding}]
__co__ void foo(stream s0, stream s1, f32[M] a, f32[N] b) {
  parallel.async<s0> p by M : block {
    a.at(p) = 1.0f;
  }
  parallel.async<s1> q by N : block {
    b.at(q) = 2.0f;
  }
}
\end{lstlisting}

In this example:

\begin{itemize}[leftmargin=1.6em]
\item \textbf{\texttt{stream s0, stream s1}}: Stream parameters passed from the host.
\item \textbf{\texttt{parallel.\allowbreak{}async\textless{}s0\textgreater{}}}: Launches the kernel asynchronously on stream \texttt{s0}.
\item \textbf{\texttt{parallel.\allowbreak{}async\textless{}s1\textgreater{}}}: Launches a second kernel on stream \texttt{s1}.
\end{itemize}
