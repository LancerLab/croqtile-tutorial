\subsection*{Event flow for one stage}

The diagram matches the code: the bootstrap triggers every \texttt{empty} event; the producer waits on \texttt{empty}, fills, triggers \texttt{full}; the consumer waits on \texttt{full}, computes, triggers \texttt{empty}. When \texttt{iv\_k} wraps modulo \texttt{STAGES}, the same physical stage re-enters the cycle.

Figure~\ref{fig:f08-fig2_event_credit_flow} traces both events through one stage.
