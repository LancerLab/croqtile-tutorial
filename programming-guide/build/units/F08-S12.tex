\subsection*{Credit flow for one stage}

The diagram matches the code: bootstrap grants empty credits; the producer waits on \texttt{empty}, fills, signals \texttt{full}; the consumer waits on \texttt{full}, computes, signals \texttt{empty}. When \texttt{iv\_k} wraps modulo \texttt{STAGES}, the same physical stage re-enters the cycle.
