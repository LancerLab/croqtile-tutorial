\subsection*{Development Utilities}

The commands above build your \texttt{.co} program. The repository's Makefile commands are useful when testing sample operators or changing the compiler itself:

\begin{lstlisting}[language={},caption={Testing sample operators}]
make help
make sample-test
make sample-test-operator OPERATOR=add
\end{lstlisting}

\texttt{make help} lists the available targets. \texttt{make sample-\allowbreak{}test} runs all sample operators; \texttt{OPERATOR=add} restricts the run to addition. Other operator names include \texttt{mul}, \texttt{relu}, \texttt{sigmoid}, \texttt{softmax}, and \texttt{tanh}. With the program built, Section 1.4 explains how to inspect the compilation commands and check its execution.
