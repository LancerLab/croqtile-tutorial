The commands above build your `.co` program. The repository's Makefile commands are useful when testing sample operators or changing the compiler itself:

```bash
make help
make sample-test
make sample-test-operator OPERATOR=add
```

`make help` lists the available targets. `make sample-test` runs all sample operators; `OPERATOR=add` restricts the run to addition. Other operator names include `mul`, `relu`, `sigmoid`, `softmax`, and `tanh`. With the program built, Section 1.4 explains how to inspect the compilation commands and check its execution.
