For example, you can inspect the generated source or the result of preprocessing before building an executable:

```bash
croq -t target -es ele_add.co -o ele_add.target.cpp
croq -E ele_add.co
croq --help
```

Replace `target` with a name reported by `croq --help-target`. Available output forms depend on the selected toolchain. Use `-v` when you need to see the actual compilation commands; Section 1.4 covers further build diagnostics.
