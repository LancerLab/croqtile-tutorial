After running `ele_add`, you can use the same command pattern for other `.co` files. Croqtile first generates target source code, then invokes the target toolchain to compile and link it. By default the output is `a.out`; `-o` gives it an explicit name.

The following options select the output form or expose a step in this process:

| Option | Purpose |
| --- | --- |
| `-o <file>` | Set the output filename. |
| `-t <platform>` | Select the target platform; list supported targets with `--help-target`. |
| `-es` | Emit target source without compiling it further. |
| `-E` | Emit preprocessed Croqtile source only. |
| `-c` | Compile to an object file without linking. |
| `-S` | Emit assembly when supported by the target toolchain. |
| `-gs` | Generate a script for subsequent compilation and execution. |
| `-v` / `--verbose` | Show the external commands invoked by the compiler. |
| `--help` / `--help-hidden` | List standard or advanced compiler options. |
